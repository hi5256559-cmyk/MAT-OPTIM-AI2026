# MAT-OPTIM AI

A Streamlit prototype for preliminary engineering material selection.

## Files
- `app.py`: Streamlit application
- `materials.csv`: materials database (same folder as app.py)
- `requirements.txt`: Python dependencies

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
Select this repository, branch `main`, and main file path `app.py`.

Note: Material values are approximate educational values. Suggestions are database-based filters, not certified engineering advice or a trained AI model.
